# SurfaceRoughness_Dataset
This repository contains a dataset of 172 images used for aluminum surface roughness measurement, collected via physical samples, Rugotest comparison charts, and web crawling. 
This is a labeled dataset with no pre-processing or augmentation applied. 
It can be used to train any CNN or Transformer model for surface roughness measurement; it was originally used to train a YOLOv8 model.

The dataset can be downloaded using <<https://huggingface.co/datasets/TimesLabPoly/SurfaceRoughness_Dataset>>
